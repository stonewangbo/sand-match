# 流沙同色消除

纯前端网页游戏：罐口沙画中的彩色沙粒按沙漏式密实塌陷与休止角雪崩流动，通过传送带上的同色沙桶吸取消除。

沙粒物理与渲染基于 **WebGL2 对角滑落 CA + CPU 列密实**，兼容 PC 与移动端（需支持 WebGL2，无 CPU 回退）。示例关卡网格约 **192×240**（CELL_SIZE=2）。渲染为点彩哑光沙质感；UI 为明亮休闲风（圆润罐口框、分段托盘、宽口沙桶）。

## 玩法

1. **上半**：圆润罐口框内是不同颜色沙粒组成的图案。
2. **中部**：分段传送托盘（默认最多 6 个沙桶）。沙桶随传送带连续水平移动；经过沙画下方时，按当前水平位置吸入**下层同色**沙粒（不可穿透异色层）。
3. **下半**：沙桶库存。仅可点击**第一行**沙桶放入传送带；取出后该列上方下沉补位。
4. 传送带上出现 **3 个同色沙桶** 时自动合并，容量为三者之和。
5. 罐内沙子全部装完即通关。

## 沙粒物理与吸取

- **沙漏式密实塌陷**：吸取后立即按列 `densify` 压实到瓶底，体内不留上升空洞（消除 CA「气泡」感）；顶面随吸沙下沉。
- **休止角雪崩**：邻列顶面高差 ≤ 1 格保持稳定（约 45° 干沙台阶）；仅更陡处顶沙滑入邻列。每遍按高差优先、摩擦随机、最多移动数粒，形成漏斗而非液面摊平。
- **沙材质感**：Blit 着色器点彩颗粒噪点 + 轻邻域明暗，偏哑光卡通沙。
- **坐标约定**：格子 `y=0` 为瓶口方向（画面上方），`y` 增大朝向瓶底；渲染与仿真使用同一套方向，避免上下颠倒。
- **传送带跟随**：沙桶 `position`（0..1 循环）映射到轨道 `left` 与沙世界列坐标；视觉与吸取共用同一位置。
- **经过位置吸取**：每个未满桶在其当前 `worldX` 附近窄列带内操作。每列仅看**最底部一颗沙**（暴露表面），颜色与桶相同才吸入——不会穿透下层异色沙；可吸列随机选取；吸后密实该列。
- **飞入动效**：粒子从**被吸走的沙格位置**飞向对应沙桶口并坠入堆积。
- **沙桶外观**：宽口卡通沙桶，桶下白字黑描边容量；罐口相框 + 分段托盘为明亮休闲布局。
- **容量**：每桶有容量上限，装满后离开传送带腾出槽位。

相关实现：`src/sand/GpuSandEngine.ts`（渲染）、`src/sand/SandWorld.ts`（densify / 休止角雪崩）、`src/ui/AbsorbFx.ts`（飞入粒子）、`src/systems/AbsorbSystem.ts` / `src/ui/ConveyorView.ts`。

## 开发

```bash
npm install
npm run dev
```

构建静态产物：

```bash
npm run build
npm run preview
```

产物在 `dist/`，可直接部署到任意静态托管，无需后端。

## 技术栈

- Vite + TypeScript
- **WebGL2** 渲染网格；**CPU densify** 列密实 + **CPU surfaceAvalanche** 自由面侧向流动
- 渲染：调色板 + **点彩哑光颗粒 / 轻邻域软光**
- 主循环：absorb+densify → 自由面雪崩 → upload → 渲染
- DOM 库存 / 传送带 UI（明亮罐口框 · 分段托盘 · 宽口沙桶）
- 吸取与通关：每帧 GPU→CPU 小块 readback（关卡网格规模下移动端可接受）
