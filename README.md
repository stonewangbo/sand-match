# 流沙同色消除

纯前端网页游戏：玻璃瓶中的彩色沙粒按真实下落物理塌陷，通过传送带上的同色瓶子吸取消除。

沙粒物理与渲染基于 **WebGL2 二维网格元胞自动机（GPU CA）**，兼容 PC 与移动端（需支持 WebGL2，无 CPU 回退）。

## 玩法

1. **上半**：玻璃瓶内是不同颜色沙粒组成的图案。
2. **中部**：传送带（默认最多 6 个瓶子）。瓶子进入吸取区后，从正上方列带的**底部表面**吸入同色沙粒（不可穿透异色层）。
3. **下半**：瓶子库存。仅可点击**第一行**瓶子放入传送带；取出后该列上方瓶子下沉补位。
4. 传送带上出现 **3 个同色瓶子** 时自动合并，容量为三者之和。
5. 玻璃瓶内沙子全部装完即通关。

## 沙粒物理与吸取

- **重力塌陷**：沙粒在网格上竖直下落，受阻时向左下/右下对角滑落；空穴由上方沙填补，整体沉向瓶底。
- **坐标约定**：格子 `y=0` 为瓶口方向（画面上方），`y` 增大朝向瓶底；渲染与仿真使用同一套方向，避免上下颠倒。
- **瓶口吸取**：传送带瓶子进入吸取窗口后，只在其正上方列带内操作。每列仅看**最底部一颗沙**（从瓶底往上的暴露表面），颜色与瓶子相同才吸入——不会穿透下层异色沙。
- **吸走后**：被吸空位由重力自动塌陷填补；每帧多步物理子步进，保证堆面尽快稳定。
- **容量**：每瓶有容量上限，装满后离开传送带腾出槽位。

相关实现：`src/sand/GpuSandEngine.ts`（GPU CA）、`src/sand/SandWorld.ts`（列带底部表面查找）、`src/systems/AbsorbSystem.ts`（吸取逻辑）。

## 开发

```bash
npm install
npm run dev
```

构建静态产物：

```bash
npm run build
npm run preview
```

产物在 `dist/`，可直接部署到任意静态托管，无需后端。

## 技术栈

- Vite + TypeScript
- **WebGL2** 双缓冲纹理网格 CA（竖直下落 + 棋盘格对角滑落）
- DOM 库存 / 传送带 UI
- 吸取与通关：每帧 GPU→CPU 小块 readback（关卡网格规模下移动端可接受）

## 目录

```
src/
  core/       主循环、状态、事件总线
  sand/       SandWorld、GpuSandEngine（GPU CA）
  bottle/     瓶子、库存、传送带、合并
  systems/    吸取、通关
  level/      关卡加载与示例
  ui/         HUD / 库存 / 传送带视图
```

## 设备要求

- 桌面：Chrome / Edge / Firefox / Safari（WebGL2）
- 移动：iOS 15+ Safari / 近年版本 Chrome WebView 等
